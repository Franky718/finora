# Publicación rápida en GitHub

1. Crea un repositorio vacío llamado `finora` en GitHub (sin README/licencia inicial).
2. Abre una terminal en la carpeta `finora-mvp`.
3. Ejecuta los comandos de publicación del README.
4. Revisa que `backend/.env` no se haya agregado. Solo debe existir `.env.example`.
5. Para desplegar, publica el backend en un servicio compatible con Node.js y configura las variables secretas en el panel del proveedor. GitHub almacena el código, no ejecuta la API por sí solo.
